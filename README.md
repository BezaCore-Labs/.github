# .github

The BezaCore Labs organization's GitHub profile.

`profile/README.md` is what GitHub renders on the organization's overview page,
the way `thejollydev/thejollydev` renders on Joseph's personal profile. It only
renders once this repository is public, so it stays private until there is a
profile worth showing.

The profile has not been written yet. Open work lives in OpenProject, project
`bezacore-github-profile`, and the workspace is
`10_Workspaces/BezaCore-Labs/Workspaces/BezaCore-GitHub-Profile/` in the
never-knowledge vault.

## Mirrors

| Forge  | Repository                                   |
|--------|----------------------------------------------|
| GitHub | `BezaCore-Labs/.github`                      |
| Gitea  | `bezacore-labs/.github`                      |
| GitLab | `bezacore-labs/bezacore-github-profile`      |
